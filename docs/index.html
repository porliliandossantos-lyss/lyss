Lyss

A personal content automation assistant for short-form video.

Lyss is a private tool built and operated by a single individual creator to help manage her own short-form video presence. It is not a public product or a multi-user service — it has one owner, and it only ever acts on that owner's own social media accounts, which she authorizes herself through each platform's official login flow.

What it does

Lyss automates the repetitive parts of running a content channel end to end:

  1. Generates a video idea and script for the owner's chosen niche.
  2. Turns the script into narration using a local text-to-speech voice.
  3. Renders a finished short-form video (captions, background footage, and optional music).
  4. Publishes the video to the owner's own account using each platform's official API — on TikTok, that means TikTok Login Kit for authentication and the Content Posting API (video.publish) to publish directly to the profile that authorized it.

Who operates it

Lyss is developed and run by an independent creator for her own accounts. There is no sign-up, no other users, and no data shared between accounts — each connected account belongs to the same owner.
